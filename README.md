4. 设置管理员密码，建议大小写字母、数字、特殊字符混着来，设完复制保存好——装完连接用的就是它，忘了得去面板看“系统密码”；

配置方面不用纠结太多：Windows Server 2019/2022最低要求1GB内存、15GB硬盘，基础套餐就能跑起来。但如果要同时开多个浏览器窗口或跑业务程序，直接上2GB内存以上的配置，RDP操作会舒服很多。

## RDP怎么连接？

Windows系统自带远程桌面，不需要额外装软件。开始菜单搜索“远程桌面连接”，或者直接运行 `mstsc`，填三个信息就行：

- **计算机**：VPS的公网IP，默认端口3389；
- **用户名**：Administrator；
- **密码**：装系统时你自己设置的那个。

Mac用户去App Store下载Microsoft Remote Desktop，填的信息一样。Ubuntu这类Linux桌面系统装一个远程桌面客户端即可，配置参数相同。

有两个容易卡住的点说一下。第一，面板里内置的VNC连接要走服务器中转，速度慢、延迟高，只适合应急或装系统时用，日常操作用RDP直连。第二，如果你买的是NAT模式的机器（没有独立公网IP），得先在丽萨主机面板里把3389端口做转发映射，拿到一个外部可访问的端口号，连接时地址填“公网IP：映射端口”的格式，比如 `1.2.3.4:54321`。独立IP的机器没这一步，直接填IP就能连。

## RDP卡怎么办？

卡顿多数时候不是机器性能问题，而是远程桌面协议本身对网络质量敏感。几个能明显改善体验的调整：

- **开BBR加速**。官方对国际线路（尤其非大陆直连的美国产品）明确建议开启BBR，降低丢包率后RDP响应会顺滑不少。
- **调低RDP画质**。远程桌面连接的“体验”选项卡里，把连接速度选“局域网（10 Mbps或更高）”，关掉壁纸和字体平滑，画面会流畅很多。
- **机房选对**。人在国内、主要拿它当远程办公机的话，优先香港CMI（平均延迟约50ms）或CN2 GIA线路，操作手感接近本地。
- **非直连线路走中转**。美国4837、纽约、芝加哥以及台湾、新加坡机房都不是大陆直连优化，直连体验一般；官方建议先经香港或日本节点中转再RDP，参考数据是香港中转延迟约30ms、日本约70ms。
